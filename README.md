# AI Filmmaking Team Collaboration & Asset Management

This repository contains coursework and UX research exploring how small AI filmmaking teams can manage shots, generated assets, and creative handoffs. The project investigates how connecting each shot to its prompts, references, generation versions, and review status could reduce repeated work and help collaborators continue one another's work.

## Course Introduction

**ITPG-GT 3017: User Experience Design** is a two-unit course at NYU Tisch School of the Arts. It develops students' critical thinking and practical skills for designing effective interfaces. Students learn UX research methods for defining problems and apply design frameworks for mapping and testing user experiences. The course includes lectures, discussions, in-class design exercises, and a final project.
